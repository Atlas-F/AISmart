## 8. 常见问题

- FAQ

  - 使用Square Line进行快捷设计导出时部分源码文件会被覆盖掉，高危操作，要注意提前保护

  - 在UIevent.c中存储自定义的事件函数（应该在外部再设置自定义文件将自定义函数存储在里面，放置被覆盖）

    自定义的函数不会被覆盖

- 故障排除

  - 点击对话框刷新文本内容

- 已知问题

  - 开发板时间获取与实际不同，需要手动校准或者...
  - 对话的循环逻辑是死的，只能强制退出
